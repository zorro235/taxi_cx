# Taxi Telegram Mini App v2
Реализовано: пассажир/водитель, профиль водителя с обязательной маркой и моделью, необязательное фото машины, рейтинг 1-5 звезд, отзывы и комментарии, минимальная цена поездки 100 ₽, комиссия платформы 10% от завершенной поездки, баланс/долг водителя, автоматическая блокировка при долге 100 ₽ и выше, endpoint для оплаты и разблокировки.
ВАЖНО: `/api/payments` — тестовый endpoint. В production его нужно заменить на webhook реального эквайринга/СБП с проверкой подписи, идемпотентностью и бизнес-аккаунтом. Пароли банков хранить нельзя.
Telegram Mini App требует HTTPS. Адрес API в frontend/index.html заменяется после размещения backend.
