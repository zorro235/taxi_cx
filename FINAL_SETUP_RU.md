# Финальная настройка Taxi Mini App + Т-Банк СБП

## Что уже сделано в коде
- пассажир оплачивает поездку наличными;
- комиссия водителя считается на сервере;
- задолженность хранится в PostgreSQL;
- водитель видит долг и кнопку «Оплатить через СБП»;
- приложение запрашивает у Т-Банка список банков СБП;
- водитель выбирает свой банк;
- сервер создает индивидуальный платеж с уникальным OrderId;
- Т-Банк возвращает deeplink для выбранного банка;
- водитель переходит в банковское приложение;
- Т-Банк присылает уведомление на `/api/tbank/notification`;
- сервер проверяет подпись, платеж ID и сумму;
- после подтверждения долг уменьшается и блокировка снимается автоматически;
- администратор видит историю платежей в разделе «Комиссия».

## Шаг 1. Т-Банк
Нужен действующий бизнес-терминал интернет-эквайринга Т-Банка с подключенным СБП.
Получите:
- TerminalKey;
- Password терминала.

## Шаг 2. Render
Создайте/обновите Web Service из этого проекта через `render.yaml`.
Добавьте секреты:
- TELEGRAM_BOT_TOKEN
- ADMIN_TELEGRAM_IDS
- PUBLIC_BASE_URL
- TBANK_TERMINAL_KEY
- TBANK_PASSWORD

`PUBLIC_BASE_URL` — HTTPS-адрес Render, например `https://ваше-приложение.onrender.com`.

## Шаг 3. Telegram
Укажите Web App URL боту на тот же `PUBLIC_BASE_URL`.

## Шаг 4. Вебхук Т-Банка
В методе Init код передает:
`https://ваше-приложение.onrender.com/api/tbank/notification`

Проверьте в настройках терминала Т-Банка, что HTTP(S)-уведомления разрешены. Т-Банк требует HTTPS и ответ `200 OK` на корректное уведомление.

## Шаг 5. Первый тест
1. Одобрите тестового водителя.
2. Создайте ему задолженность комиссией после завершенной поездки.
3. Откройте «Комиссия».
4. Нажмите «Оплатить через СБП».
5. Выберите банк.
6. Проверьте переход в банковское приложение.
7. После оплаты проверьте, что статус в админке стал `PAID`.
8. Проверьте, что долг стал 0 и `blocked=false`.

## Важно
Автоматическое подтверждение денег реализуется через уведомление Т-Банка, а не через кнопку «Я оплатил». Клиентская часть никогда не может сама объявить платеж оплаченным.
