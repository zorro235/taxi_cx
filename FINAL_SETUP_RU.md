# Финальная настройка Taxi Mini App v4

## 1. Render

Используется существующий **Web Service**. Root Directory должен быть пустым — не `frontend`.

Сборка идёт из корневого `Dockerfile`.

Обязательные переменные:

- `TELEGRAM_BOT_TOKEN`
- `ADMIN_TELEGRAM_IDS`
- `PUBLIC_BASE_URL` — например `https://taxi-cx-1.onrender.com`

Отдельный PostgreSQL для запуска этой версии не нужен.

## 2. Проверка сервера

После Deploy открыть:

`/health`

и получить:

`{"ok":true,"version":"4.1.0"}`

Также работает `/api/health`.

## 3. Telegram

URL Mini App должен указывать на тот же HTTPS-адрес Web Service.

Сервер автоматически устанавливает Telegram webhook при наличии `TELEGRAM_BOT_TOKEN` и `PUBLIC_BASE_URL`. Для webhook используется секретный заголовок, производный от токена; отдельную переменную для него задавать не требуется.

## 4. База данных

По умолчанию SQLite: `/app/storage/taxi.db`.

Схема создаётся автоматически при первом запуске. Включены внешние ключи, WAL и busy timeout. Для долгосрочного хранения на Render этой версии нужен один Persistent Disk с Mount Path `/app/storage`; SQLite и загруженные файлы находятся внутри него. Подробные действия — в `RENDER_DISK_SETUP_RU.md`.

## 5. Платежи

Наличные доступны сразу.

Онлайн-оплата пассажиром требует `TELEGRAM_PAYMENT_PROVIDER_TOKEN`.

Автоматическая оплата комиссии водителя через СБП требует действующего бизнес-терминала интернет-эквайринга Т-Банка и:

- `TBANK_TERMINAL_KEY`
- `TBANK_PASSWORD`

Без этих переменных функция комиссии сообщает, что платёжный провайдер не настроен, но основное приложение продолжает работать.
