# Постоянный диск Render для Taxi CX

Для этой версии база SQLite и загружаемые файлы должны находиться на постоянном диске Render.

## Настройки существующего Web Service

1. Откройте `taxi_cx-1` в Render.
2. Откройте **Disks**.
3. Нажмите **Add Disk**.
4. Mount Path: `/app/storage`
5. Размер: начните с минимального доступного размера, который Render предлагает для вашего тарифа.
6. Сохраните. Render выполнит новый deploy.

После этого приложение хранит:
- SQLite: `/app/storage/taxi.db`
- фотографии/файлы: `/app/storage/media/`

Только файлы под `/app/storage` сохраняются между deploy/restart. Render указывает, что без Persistent Disk файловая система сервиса эфемерна.

## Важно

- Не указывайте `/app` как Mount Path.
- Не меняйте Root Directory на `frontend`. Для этой версии Root Directory должен оставаться пустым.
- Не создавайте второй Render Service.
- Диск привязывается к одному экземпляру сервиса; масштабирование на несколько экземпляров с этим диском не используется.

## Проверка после deploy

Откройте:
`https://taxi-cx-1.onrender.com/health`

Ожидается HTTP 200 и JSON с `ok: true` и версией `4.1.0`.

Для проверки сохранения данных сделайте тестовый заказ, затем выполните обычный redeploy без удаления диска и проверьте, что заказ остался. Не удаляйте диск во время проверки.
